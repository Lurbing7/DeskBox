# CPU 采集组件第三方许可

本组件使用未经修改的 LibreHardwareMonitorLib 0.9.6；源码：https://github.com/LibreHardwareMonitor/LibreHardwareMonitor 。LibreHardwareMonitorLib、DiskInfoToolkit、RAMSPDToolkit-NDD 和 BlackSharp.Core 使用 MPL-2.0，完整许可证见同目录 MPL-2.0.txt；HidSharp 完整许可证见 HidSharp.txt。

此次发布补齐 Mono.Posix.NETStandard 1.0.0 和微软依赖的完整通知。依赖版本及校验散列记录在 packages.lock.json；库未经修改，对应源代码可通过下列项目和 NuGet 包的元数据链接取得。
