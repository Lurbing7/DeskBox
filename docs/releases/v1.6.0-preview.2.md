# DeskBox 1.6.0-preview.2 · 通知恢复修复

发布日期：2026-10-06；来自 `Lurbing7/DeskBox` fork，预览版。

## 更新内容

- **微信、QQ 通知恢复**：修复隐藏任务栏后微信通知无法打开、QQ 显示停滞页面。通过各自的应用托盘路径恢复现有窗口；失败时保留提醒。用户已确认本机微信和 QQ 恢复正常。
- **豆包运行图标去重**：识别同一安装目录的启动器及实际进程，已固定主栏的应用显示运行点，避免再次出现在临时运行区。
- **失败提示**：成功打开应用后清理历史启动失败状态；感叹号提供说明提示。

## 下载与依赖

- 安装包 `DeskBox_Setup_1.6.0-preview.2_x64.exe`，附 SHA-256 校验文件。
- x64，最低 Windows 10 21H2；建议 Windows 11。
- 沿用框架依赖安装方式，缺失依赖时联网下载 .NET 10 Runtime 与 Windows App Runtime 2.4；不是离线 AOT 安装包。
- 保留 GPL-3.0-only 许可证与上游署名，监控依赖通知随包提供；对应源码见此版本标签。

## 验证边界

- 本机微信 4.1.15.13、QQNT 9.9.35-52892 通知恢复获用户实机确认。不同版本的托盘协议可能有差异，未保证所有通信软件兼容。
- 发布包构建与回归结果在完成后记录。
