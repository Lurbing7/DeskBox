# DeskBox 1.6.0-preview.1 · Dock 与系统监控里程碑

发布日期：2026-10-05。此版本来自 `Lurbing7/DeskBox` fork，为预览版。

## 更新内容

- **Dock 应用管理**：主栏手动排序和拖放插入，文件夹按名称排序，嵌套子栏逐级展开；空文件夹自动删除，点击空白收起。
- **运行程序与通知**：默认显示正在运行的程序；主栏固定入口显示运行圆点，点击切换现有窗口。独立左侧通知区显示红点，右键运行项可关闭窗口或添加到 Dock。
- **位置与多屏**：支持各屏复制、主屏或指定屏幕。左右居中自动改为纵向，原最左侧入口及通知区置于底部；四角按边缘定位，主栏达到最大长度时同比缩放。
- **原生设置**：统一设置页，图标间距、屏幕边距、拖动锁定、文件夹展开延迟/悬停和子栏滚轮步幅。子栏支持普通滚轮与触控板横向滚动。
- **系统监控**：CPU/GPU 占用与频率、可用温度/功耗、内存、显存、网络速率与所选网卡 IP。支持独立屏幕与九宫格位置设置；硬件未提供的传感器显示不可用。

- 安装包：`DeskBox_Setup_1.6.0-preview.1_x64.exe`，附 `.sha256` 校验文件。
