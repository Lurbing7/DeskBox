# DeskBox 1.6.0-preview.3 · 时间与监控卡片优化

发布日期：2026-10-07；来自 `Lurbing7/DeskBox` fork，预览版。

## 更新内容

- **居中双历时间**：时间保持第一行，第二行显示“2026年10月6日 / 丙午年八月廿六”，第三行显示星期；保留日期、年份和星期开关。其他语言使用当地日期，中文繁体沿用现有转换。
- **文字可读性**：根据背景互补色和亮度计算文字颜色，复杂背景使用局部衬底；高对比度模式采用系统颜色。
- **Bing 每日壁纸**：默认获取当日最新图片，离线保留缓存，失败延迟重试。仅作用于时间卡片背景。
- **监控等比缩放**：内容、字号、图标和间距整体缩放，窗口高度随内容收紧；支持分组或单项关闭指标，默认全部启用，按需采集数据来源。
