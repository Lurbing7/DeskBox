# Dock 空文件夹清理与空白点击收起

## 调研报告
现有移动会移除旧位置快捷方式，但保留空目录。子 Dock 只依赖窗口失活收起，点击同一窗口空白或不改变激活的桌面区域可能不触发。

## 问题澄清
用户授权移动成功后删除被移空的 Dock 自有真实目录，逐级清理空父目录但保留 Dock 根目录；含隐藏文件、其他文件或子目录的目录不删除，不遍历外部链接目标。点击主/子 Dock 空白与所有面板之外收起整条层级，图标和滚动条点击保持正常，拖放保留已验收行为。

## 开发规划
记录内部源父目录，导入成功后非递归删除确认空的自有目录；先做独立目录探测。补充空白指针处理与仅在子 Dock 打开时存在的鼠标按下监听，监听回调只入 UI 队列，不阻塞/吞掉点击，关闭后卸载。更新文档，停止标准实例、构建、重启。

## 代码开发
实现已完成，待实机交互确认。源目录在移动前收集，移动完成后只处理这些自有源目录及连续空父目录，删除使用非递归方式；自动清理不扫除用户刚建的无关空目录，竞争或权限失败保留目录。空白点击通过主栏/子栏指针事件处理，面板外点击由按需鼠标监听入 UI 队列，原点击照常传递，关闭全部子 Dock 后卸载监听。
