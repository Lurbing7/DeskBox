# Dock 展开、九宫格与拖放流程

## 调研与问题

用户报告原生 Flyout 覆盖主 Dock。当前面板使用同一 XamlRoot 的 Flyout，在短小工具窗口中无法保证所需的屏幕外展开几何；此限制需要绕开，不能继续仅修改 Placement。项目已有 `StackPopoverHostWindow`，提供独立的无边框、可复用窗口与退出清理，可用于 Dock 目录展开；不改变其他卡片的浮出面板。

已检查录像 0、2、4 秒画面：点击目录后主栏被展开内容遮挡，且目录内容下沿被裁切。结合源码确认现有 Flyout 无法满足独立展开要求；改用独立宿主并通过工作区坐标定位。截图只保存于本地忽略目录。

## 澄清

已确认：位置九宫格 1–9，默认 2；2 向下展开，8 向上，其余优先向上，空间不足转向下。目录单行展开且可以比主 Dock 宽，最大工作区宽度比例默认 0.618，可设置；透明背景提供选项和系统回退。

追加拖放：主 Dock 自动扩宽且不出现滚动条；超屏幕上限用更多菜单。目录展开栏可横向滚动。拖到目录图标加入该目录，拖到边缘/空白加入主栏，拖到应用图标用其打开。默认复制/创建快捷方式，源文件保留；不得把打开失败降级为导入。临时文件用应用打开的生命周期需特别处理，未能持久化时拒绝，不能启动后立即清掉参数路径。

## 规划

1. 先实现独立目录宿主与屏幕几何：主 Dock 完整保留，分离内容树、注册释放和交互生命期；上下回退仍不得覆盖主栏。
2. 九宫格原生 3×3 按钮设置、比例与透明选项；配置沿用 Metadata。主窗尺寸/位置由宿主计算。
3. 拖放按命中目标分类，复用现有快捷方式启动/创建服务；记录拒绝和失败，避免重复导入及临时路径失效。
4. 快速几何/语法检查、Debug 构建和标准实例重启；实机展开、拖放、屏幕边缘、DPI、主题和用户视觉分别验收。

## 开发

已实现独立目录宿主、九宫格布局设置、宽度比例和透明磨砂选项。主栏禁用横向滚动，完整图标溢出转入更多菜单。物理目录/EXE 创建快捷方式，LNK/URL 复制；目录目标导入到目标目录，应用目标执行打开且失败不降级导入。快捷方式服务为 EXE 使用其父目录作为工作目录。

配置沿用 Metadata，默认位置 2、最大比例 0.618、透明开启。设置入口为 Dock 右键菜单的“Dock 布局设置”；设置面板也使用独立宿主，避免短窗口裁切。已有文件目录、其他卡片和 Nexus 未更改。

构建修正记录：首轮发现 WidgetConfig 属性命名和 Win32Helper 命名空间引用错误，修复后二轮 Debug 构建成功；收尾修改后再次构建成功（0 错误、22 项警告，无本次新增警告）。按约定先停止仓库进程，再构建并启动 canonical Debug 实例。
