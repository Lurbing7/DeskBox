## 开发规划

1. 补充实机验收记录，版本统一为 `1.6.0-preview.2`，数字版本为 `1.6.0.1`。
2. 仅暂存本轮修复；混合文件选择必要内容。从已提交源码导出干净副本。
3. x64/win-x64 锁定恢复、修复相关测试、框架依赖 Release 发布、安装器编译及载荷/版本/哈希检查。此前受杀毒软件拦截的 AOT 审计不属于本次非 AOT 发布关口，不绕过拦截。
4. 推送分支与版本标签，用 GitHub CLI 发布预览版及安装包、SHA-256 资产；核对远端结果。
5. 按项目约定重建并恢复标准 Debug，记录发布结果。回退使用上一版发布与对应源码，不清理用户数据。
