# 1.6.0-preview.3 发布流程

开始日期：2026-10-06；发布日期：2026-10-07；阶段：已完成，GitHub 预览版已发布。

## 调研报告

沿用 preview.2 的 x64 框架依赖联网安装包，目标为 `Lurbing7/DeskBox`。本轮范围见 [时间与监控](2026-10-06-clock-monitor-adaptive.md) 和 [双历布局](2026-10-06-clock-lunar-preview.md)。

## 问题澄清

用户确认 HTML 布局并授权原生改造，随后明确要求“提交并发布版本”。只发布本轮时间/监控功能，工作区其他 Dock、文件网格与性能研究修改保持独立。视觉、真实跨天、多 DPI 和安装升级尚未完整实测，作为预览版验证边界公开记录；不自动安装覆盖当前配置。

## 开发规划

1. 统一文本版本 `1.6.0-preview.3`、数字版本 `1.6.0.2`，混合文件仅暂存当前任务内容。
2. 提交后导出干净源码，x64/win-x64 锁定恢复、相关回归、Release 发布。
3. 检查安装载荷、许可证、原生架构与版本，生成 SHA-256。
4. GitHub CLI 推送并发布预览版，核对远端标签和资产摘要；恢复标准 Debug。

## 代码开发

源码基线 `41444b6635bc0392345f85fc49f6a7d794d5cdfe`，55 个文件；混合窗口、翻译和采样文件仅暂存本轮功能，其他优化保留工作区。发布不修改用户数据结构；旧配置缺失的新选项采用兼容默认值。

干净源码锁定恢复通过，完整项目中 40 项相关回归通过（495ms），x64 框架依赖 Release 通过。初次载荷检查发现默认未包含原生模块，显式启用 `DeskBoxRustNative=true` 重新发布后通过；首次安装器输出参数带额外空格，修正后 Inno Setup 6.7.3 编译通过（25.672 秒）。最终载荷 169 项文件、20 项关键文件、5 项原生 PE x64、许可证检查通过且不含 PDB。SensorHost 3 条有效格式采样，关闭输入后正常退出、无标准错误。数字版本 `1.6.0.2`、大小与 SHA-256 见 [发布说明](../releases/v1.6.0-preview.3.md)。

Git HTTPS 推送连接重置，改用 GitHub CLI Git 对象 API；API 将时间戳规范化为 UTC，源码提交仅转换时区表述，树内容和时间点不变；保留消息末尾换行后本地/远端 SHA 完全一致，无强制推送。标准 Debug 重建通过（0 错误、22 条现有警告，74.78 秒）。
