日期：2026-10-04。状态：用户已确认首批 A，代码开发已完成，实机验收待完成；B 中的运行列表及运行标记现已单独获授权，默认开启，见 [运行应用任务](2026-10-04-dock-running-apps.md)；其余 B/C 未实施。

## 调研报告（已完成）

### 参考中值得吸收的优点

用户提供的 Nexus 页面将内容、位置、行为、外观、维护分别组织；常用项有直观开关，尺寸和延迟有明确数值，锁定能够防止误拖动，备份提供恢复路径。DeskBox 借鉴这些能力和分组，界面沿用现有 WinUI 设置窗口与系统主题，不复制参考产品的皮肤和密集横向页签。

### 当前实现核对

| 能力 | 当前状态 | 建议 |
| --- | --- | --- |
| 九宫格与最大宽度 | 布局浮出设置已有；无中央格，默认顶部居中，最大宽度 0.618 | 在统一设置页提供可发现入口，沿用当前值 |
| 图标大小、名称、更多按钮、透明背景 | 分散在空白菜单和布局浮出设置 | 汇总展示，不改变已有配置 |
| 满宽处理 | 主栏全项等比缩放；子栏横向滚动 | 保留，间距调整也参与同一宽度计算 |
| 间距与屏幕留白 | 图标间距固定 2 DIP；宿主边距固定 12 DIP | 提供有限范围可调值 |
| 防止误拖 | 宿主已有位置和尺寸锁定；没有独立图标排序锁定 | 显示现有锁定状态，另加图标拖动锁定 |
| 文件夹展开 | 点击展开；拖放停留 600 ms 展开 | 拖放展开延迟可调；普通鼠标悬停展开另设开关，默认关闭 |
| 子栏滚动 | 普通滚轮转换横移，每格约 3 项；原生触控板平移保留 | 普通滚轮步幅可调，不改变触控板原生增量 |
| 消息关注 | 独立左侧入口、红点、现有窗口激活；微信获用户确认 | 保留语义，其他应用逐项验收 |
| 运行中应用 | 尚无完整任务列表或运行状态模型 | 后续独立实现，不能把关注事件当运行列表 |
| 自动隐藏、边缘唤醒 | 当前 Dock 尚无独立完整状态机 | 后续独立实现，先验证可唤醒与拖放安全 |
| 窗口层级 | 使用共享外壳的层级机制 | 不通过 Dock 设置误改其他卡片；独立置顶另行评估 |
| 开机自启与备份 | 项目已有通用设置和数据备份服务 | 提供导航入口，避免再做一套；核查 Dock 映射目录是否在备份范围内 |

接入点：`DockVisualLayout`、`DockAttentionLayout` 管理几何；`DockWidgetContent` 及 DragDrop/Scrolling/Placement 分文件管理交互；`ContentWidgetWindow.Dock` 管理屏幕布局；`SettingsWindow` 已有功能格子导航和独立监控设置页，可按相同方式增加 Dock 设置。

官方核查：

- [NavigationView](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/navigationview)：支持原生、自适应导航。方案使用现有设置导航，不将全部选项堆到常驻 Dock。
- [应用桌面工具栏](https://learn.microsoft.com/en-us/windows/win32/shell/application-desktop-toolbars)：AppBar 有屏幕占位、自动隐藏和系统任务栏协调规则。当前悬浮 Dock 不是 AppBar；自动隐藏与预留屏幕空间不能当作同一开关。
- [RegisterShellHookWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registershellhookwindow)：关注、创建、销毁、激活是不同事件；该 API 有兼容性限制，运行任务列表须初始化枚举并具备恢复核对路径，不能只复用闪烁队列。

本机未发现 WinApp CLI，未进行 find-ui/find-api 查询；不自动安装或升级依赖。正式实现前按项目实际引用检查用到的控件/API。

### A：首批设置与交互细化

入口：设置 → 功能格子 → Dock；主栏空白右键保留快捷入口。已有布局浮出入口导航到统一设置页，避免两份逻辑与两套状态。

| 分组 | 选项 | 初始/兼容值 | 行为 |
| --- | --- | --- | --- |
| 位置 | 无数字九宫格，排除中央 | 保留现有值，缺失为顶部居中 | 沿用当前工作区和屏幕定位 |
| 位置 | 距屏幕边缘距离 | 12 DIP，范围 0–64 | 只调边缘轴留白，中央轴保持居中；屏幕不足安全钳制 |
| 位置 | 最大宽度比例 | 保留当前，缺失为 0.618，范围 0.3–0.95 | 主栏全项缩放，子栏滚动，均不得越屏 |
| 外观 | 图标尺寸、名称、透明背景、更多按钮 | 保留当前值；尺寸继续 32/40/48 DIP | 复用已有设置与共享材质 |
| 外观 | 图标间距 | 2 DIP，范围 0–12 | 根/子栏、关注区、自然宽度和满宽公式统一计算 |
| 行为 | 锁定图标拖动 | 关闭 | 禁止内部图标排序和拖出；外部拖入/文件投递保留，清楚说明锁定范围 |
| 行为 | 锁定 Dock 位置 | 显示现有状态 | 复用 IsPositionLocked，不另存冲突值 |
| 子 Dock | 拖放停留展开延迟 | 600 ms，范围 200–1500 | 当前拖放行为可调；取消、切换、关闭时停掉计时器 |
| 子 Dock | 普通鼠标悬停展开 | 关闭；开启后使用上述延迟 | 同级切换替换旧分支，菜单/拖动期间避免重复触发，点击仍立即展开 |
| 子 Dock | 普通滚轮每格移动项数 | 3，范围 1–6 | 累计连续滚轮，支持高分辨率增量；触控板/水平输入保留原生处理 |
| 维护 | 打开 Dock 目录、移除项备份、转到通用备份与开机自启设置 | 复用现有入口 | 不直接改变启动项；不宣称普通数据备份已包含外部映射目录 |

设置修改即时生效，控件先初始化再挂写入事件；非法配置回退，不改快捷方式目标。每项有独立恢复默认操作；恢复 Dock 设置不清空应用、名称、根目录、排序记录或通知队列。选项数量较多，必须使用设置窗口，不继续扩高窄浮出面板。

### B：运行中应用与启动方式（运行列表已单独授权，其余后续）

- 固定入口运行标记：默认开启；使用低干扰状态点，区别消息红点。
- 固定入口点击方式：用户最新确认主栏运行应用直接切换现有窗口，未运行才启动；已按 [运行应用追加任务](2026-10-04-dock-running-apps.md) 实施。额外的启动方式选择器尚未实施。左侧通知始终激活通知对应窗口。
- 显示未固定的运行中应用：用户最新要求默认开启；独立区域，按进程/窗口身份去重，不把同名不同程序合并。临时项不写入 Dock 目录；多窗口选择菜单。此默认值替代早期默认关闭的建议。
- 显示器选择：拔除屏幕后回退可用工作区，并保留目标选择以便重连；验证异构 DPI。独立置顶先评估共享外壳影响。

须覆盖应用多进程、多窗口、特殊启动参数、管理员窗口、Explorer 重启；无法激活时给出可理解反馈，不能无提示启动替代实例。

### C：自动隐藏与节制动效（后续）

- 自动隐藏默认关闭；隐藏/唤醒延迟可调，边缘唤醒不激活应用、不抢焦点。
- 鼠标在主栏、任意子栏、菜单或拖动状态时保持显示；关注消息可临时显现，处理完恢复原策略。
- 全屏时策略和热键救援入口单独设计；不能完全隐藏后没有唤醒路径。
- 默认仅系统动画，尊重禁动画/省电。悬停放大若增加，应不改变排序命中或屏幕边界。

托盘接管、任务栏隐藏、AppBar 预留空间、主题包、倒影、声音和装饰循环暂不列入本轮。需要时再独立调研与确认，不因参考图中存在而照搬。

1. M2 记录与本地源代码恢复快照，保存配置和自有入口的本地副本；不建立指向旧提交的误导性 Git 标签。

5. DragDrop 的锁定仅限制内部启动拖动；保持外部落点逻辑。展开计时器区分普通悬停和拖放来源，移出、同级切换、窗口关闭时清理。Scrolling 仅调整普通滚轮步幅。
6. 快速边界探测、静态审查、本地化 JSON 检查；按项目约定停止仓库实例、构建、重启 canonical Debug。真实鼠标、触控板、视觉及恢复另行验收。
7. 更新 Design 和项目记忆；A 完成后再评审 B 的运行窗口模型，不跨批次混做。

回退：先回到 M2 源码恢复副本并重建，再恢复有问题的 Dock 设置键；不得用旧布局整体覆盖用户实施后的应用增删。设置恢复通过既有服务，个人配置副本不提交仓库。
