# Dock 开发流程

## 调研报告

见 [调研报告](../design/dock-research-2026-10-03.md)。本机合成窗口闪烁监听实测成功；按用户授权，调研无阻断后进入计划和开发。

## 问题澄清

第一版：独立 Dock、单击应用启动/切换窗口、单击目录向上展开内部图标、关注标记及目录聚合、拖入快捷方式、名称排序与配置恢复。保留原应用栏和监控，不恢复 Tags、不读取消息内容、不自动停止 Nexus/隐藏任务栏。默认底部居中，先不实现完整任务栏替代、托盘或窗口缩略图。

## 开发计划

2026-10-03 用户反馈首版 Dock 形态不协调；[视觉优化方案](../design/dock-visual-optimization-2026-10-03.md)已获用户“按方案推进”确认，现进入实施。沿用文档先行与项目 UI 技能，不把首版构建结果作为新方案验收。当前责任范围为 Dock 内容、宿主尺寸/标题接入和必要设置、本地化；不修改其他卡片或 Nexus。

1. 事件监听与状态管理：注册 Shell 消息、匹配进程路径、激活/销毁清理、手动清除、注销释放。
2. Dock 内容：复用原生 Button/Image/Flyout/ScrollViewer 与主题资源；目录点击向上展开，图标读取异步并缓存，扫描非递归。
3. 接入既有窗口/provider/registry 与功能开关；原生拖放路由到 Dock，只复制 .lnk，不移动源文件。
4. 设置持久化沿用 Metadata 与映射目录，不新增序列化 context；本机创建独立测试 Dock，现有应用栏不转换或删除。
5. 静态审查、快速探测、Debug 构建和标准实例重启；验收标明实际与合成结果，Nexus 留待用户确认替换。

## 代码开发

### 视觉优化实施

- 主栏采用项目 SubtleButtonStyle，默认图标 40 DIP、点击区域 56 DIP，移除常驻名称和独立方框。主栏名称用系统 ToolTip；文件夹面板保留名称。
- 新增 `DockVisualLayout` 与宿主 `ContentWidgetWindow.Dock.cs`。宿主按内容自动调整宽高、保留当前水平中心和底边，最大宽度为所处屏幕工作区的 80%；超出时单行滚动并提供全部项目菜单。当前与 Nexus 共存的试用位置保持，不自动移到底边覆盖 Nexus。
- 只对 Dock 进行一次呈现配置迁移：默认隐藏标题；保留用户明确的 Standard/Compact 设置。自动尺寸模式阻止普通边框缩放，右键可关闭自动尺寸；增加 32/40/48 图标与常驻名称开关。
- 目录面板支持切换/收起，打开状态有符号指示；背景留白使用宿主拖动机制，按钮不触发窗口拖动；Shift+F10 打开菜单。
- 错误通过紧凑状态入口展开，不长期撑高窗口；关注入口尺寸参与布局，保持现有关注语义。
- 初轮 Debug 构建成功，运行日志记录五项实际窗口收缩至 320 × 72 DIP、Shell 监听注册成功。背景拖动补充阶段发现 OriginalSource 类型不匹配，已修正后重新构建；不把初轮构建替代最终构建检查。
- 实际鼠标、深色/高对比度、文字放大、跨屏和真实微信验收仍待处理；不能宣称已通过 Windows 原生视觉验收。完整测试套件/AOT 未运行。
- 最终 Debug 构建通过（0 错误、22 项既有警告），JSON/本地化键和 `git diff --check` 通过；已从标准 Debug 路径重启唯一实例，优先级 Normal。本次只改 Dock 呈现和必要宿主接入，原应用栏、性能监控及 Nexus 保留；未公开发布。

首版代码已完成。新增 `DockAttentionListener`、`DockDirectory`、`DockWidgetContent` 和 provider；接入枚举、窗口注册、功能开关、默认尺寸/位置、标题、本地化及原生拖放。沿用现有布局存储，新增枚举放末尾，不改变旧值。

实际行为：单击应用启动或激活匹配进程；单击目录由原生 Flyout 向上展开一排图标，可横向滚动；根目录和已扫描的一级目录显示关注标记，未固定应用也可从全局提醒入口找到。数字表示请求关注的应用数，不表示未读消息数。窗口激活/销毁或手动清除移除提示；程序重启不恢复历史提醒。监听注册失败显示说明；收到 TaskbarCreated 时尝试重新注册，尚未真实重启 Explorer 验证。

每层最多显示 200 个可启动项，名称排序。图标使用现有缓存服务，目录变化通过 watcher 去抖刷新，Shell 事件直接刷新提醒，不持续扫描任务栏。拖放仅复制 `.lnk`，不覆盖同名文件，不移动源文件。文件夹配置通过“打开 Dock 目录”管理，首版没有独立 Dock 设置页面。

本机已创建独立试用 Dock，示例快捷方式为复制，原应用栏和监控保留；默认在主屏底部居中并留 100 DIP 间距，方便与 Nexus 同时试用。窗口和映射目录随既有布局保存。私人布局备份和探测代码存放 `.artifacts/dock-probe/`，不进入提交。

### 手动验收步骤

1. Dock 单击“沟通”等文件夹，应在上方展开一排图标；单击图标启动，点击外部或 Escape 关闭。
2. 将一个 `.lnk` 拖入 Dock，应增加入口，源文件保留；重复拖入同名文件不得覆盖。
3. 微信保持后台，请他人发送消息并触发任务栏闪烁，检查应用/目录及全局提醒入口；不需要发送或读取消息内容。
4. 激活微信后提醒应清除；重新触发后也可右键手动清除；关闭请求关注的窗口应清除该窗口提醒。
5. 以普通用户权限运行，测试任务栏隐藏、微信托盘状态、Explorer 重启及再登录；不将合成探测作为这些场景的证明。
6. 检查原应用栏、性能监控仍可使用，退出 DeskBox 后无新 Dock 常驻进程；重启后目录和位置恢复。
