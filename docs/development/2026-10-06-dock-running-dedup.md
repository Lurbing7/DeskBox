# 豆包运行入口重复：开发与验收

日期：2026-10-06；当前阶段：本地交付，等待用户交互验收。

## 1. 调研报告（已完成）

用户截图显示主栏豆包与临时运行区豆包同时出现。本机只读核对：主栏快捷方式目标为 `<安装目录>/Application/Doubao.exe`，窗口进程为同目录的 `app/Doubao.exe`；前者版本信息为 Doubao Launcher，后者为 Doubao，同一公司。`DockWidgetContent.Running.cs` 的运行点、运行项排除与固定入口判断均只比较完整路径。目录移动没有改变快捷方式目标，根因是启动器与实际程序路径不同，不是移出 AI 文件夹造成的缓存问题。

## 2. 问题澄清（已完成）

主栏已有豆包时不再单独列出运行入口，原图标显示运行点，点击激活已有窗口。仅修复运行应用身份匹配；不修改快捷方式、分类、顺序或用户数据。不使用窗口标题或仅文件名进行宽泛匹配。目标明确、无架构及数据变更，直接实施。

## 3. 开发规划（已完成）

1. 建立统一路径匹配规则：原路径精确匹配；另支持同安装目录的同名 EXE 启动器与直接 `app` 子目录程序。其他目录、其他文件名、非 EXE、不可用路径不建立别名。
2. 在运行标记、主栏去重、运行项图标来源、添加到 Dock 和复用原快捷方式中共用规则。兼容文件夹移动与现有多屏共享快照。
3. 用针对性测试覆盖真实路径模式和误合并边界；按项目要求停止仓库实例、构建标准 Debug 并重新启动。保留当前无关优化修改。
4. 回退只需撤销本任务匹配规则和调用，不需要恢复用户配置。此次不公开发布。
