# 时间卡片农历与居中布局：开发流程

日期：2026-10-06；阶段：原生接入及针对性验证完成，标准 Debug 已启动，待实机视觉验收。

2026-10-07 发布更新：用户明确授权提交与发布，已纳入 [v1.6.0-preview.3](https://github.com/Lurbing7/DeskBox/releases/tag/v1.6.0-preview.3)。完整项目中 40 项相关回归及 x64 Release/安装包检查通过；视觉、真实跨天与安装升级继续保留未验证状态。详见 [发布流程](2026-10-06-preview3-release.md)，此记录更新后文未发布状态。

## 1. 调研报告

现有 `GlanceWidgetContent.xaml` 已有居中模式，但日期和星期横排，主时间卡片没有独立农历行。时间使用系统字体、SemiBold 和随尺寸计算的字号；本次样板沿用这一层级。项目已有 `GlanceTraditionalCalendarService` 的农历格式化能力，后续原生实现先评估复用，不引入第二套农历数据表。

HTML 仅供信息布局确认，不作为 Windows 原生材质或农历生产实现验收。预览使用浏览器内置 `Intl.DateTimeFormat` 的中国农历，保留闰月，并转换为“初一/廿六”等中文日名；无支持时明确提示，不显示编造的农历日期。

## 2. 问题澄清

用户先看 HTML 样板，随后确认原生接入。最终调整：去掉独立年份行，阳历年份并入月日；右侧追加农历对应的干支年，以“/”分开，例如“2026年10月6日 / 丙午年八月廿六”。保留前轮农历月日，用户所说“甲午年”作为纪年格式举例，不固定为甲午。干支年按中国农历的年界计算，不直接套用阳历年份；春节前可与阳历年不同。信息从上到下为时间、两种完整日期、星期，整组及各行居中。时间字体样式延续现有设置，不追加生肖、节日或完整月历。

## 3. 开发规划

用户已回复“对，就是这样，准备改造吧”，确认最终三行稿并授权原生接入。原生阶段按以下顺序实施：

1. 从现有传统历服务提取其中国农历纯计算，日历网格保持现有输出；为居中时间卡片组合完整阳历与干支年农历日期。尊重日期/年份/星期开关；传统中文沿用繁体转换，其他语言保留当地日期表现。
2. 居中模式改为时间、双历日期、星期三行；时间字体和字号计算保持，日期 12–14 DIP 随宽度调整、居中并允许窄尺寸换行；日历与其他布局不顺带改动。
3. 新日期绑定纳入自动对比度处理，跨天、恢复可见、语言/设置变化沿用现有刷新。仅为当前用户时间卡片启用确认稿所需的显示项和居中布局，先保留原配置副本，不对全部用户旧配置强制迁移。
4. 快速验证中国农历年界、闰月、日期开关、格式回退与 XAML；按项目约定停止仓库实例、构建、启动标准 Debug。真实外观/缩放与设置交互仍由实机验收，本轮不发布。

前期样板阶段记录：

1. 在 `docs/design/previews/clock-lunar-centered.html` 制作独立样板，不依赖外部脚本或服务。
2. 提供浅/深背景、尺寸和日期切换，以及本地背景图片预览；控件在卡片外，卡片只显示目标信息。
3. 浏览器核对行序、农历日期、尺寸和溢出，打开预览供用户查看。
4. 样板确认后另行记录原生接入计划：复用农历格式化、午夜刷新、设置兼容与新文字的自动对比度。

## 4. 代码开发

原生代码已实施并完成针对性验证：

- `GlanceChineseCalendarFormatter` 提取已有中国农历算法，供日历网格与时钟复用；日历原有月首/日名/标题空格规则保留。组合阳历与干支年农历日期，年份关闭时同时隐藏两历年份；系统农历范围之外仅显示可用阳历日期。
- `GlanceWidgetViewModel.CenteredDateText` 与 `CenteredDateFontSize`、NativeAOT 绑定清单接线；中文显示双历、繁体用现有转换、其他语言保留当地日期。沿用启动、分钟/跨天、恢复可见、语言与设置变化刷新。
- XAML 居中模式改为三行，新增日期行居中且可换行；保留时间字体及用户设置。新文字接入自动对比度，日期值变化也触发防抖刷新；其他布局不变。
- 当前本机时间卡片原配置为 Calendar，日期/年份/星期均已开启；已在本机备份原配置，仅改该卡片为 Centered、关闭月历网格，保持图片和字体配置。没有强制迁移所有卡片配置，模型默认值未修改。
- 新增 `GlanceChineseClockDateTests`，覆盖春节前年份、闰月及月序恢复、隐藏年份、范围外回退、原有日历呈现。

已完成独立 HTML 样板：320×260 默认尺寸，时间字号 57.5、字重 600，沿用现有响应尺寸计算规则；最新为时间、完整双历日期、星期三行居中。完整双历日期为“阳历年月日 / 干支年农历月日”，干支来自农历格式化结果的 `yearName`；春节前年份按农历处理。日期字号随宽度在 12–14 间变化，极窄空间可换行，分隔符和农历作为同一单元避免孤立分隔符。整组保留无障碍名称。支持浅深示意背景、本地图片、260–420 宽度、日期/时间及实时切换；本地图片仅使用 Blob URL，离开页面释放。新增样板与任务记录；无产品代码、配置迁移和依赖改动。
