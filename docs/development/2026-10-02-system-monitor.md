## 2. 问题澄清

### 第二轮：参考图与 IP（进行中）

用户要求紧凑 CPU/GPU 分组、彩色指标图标、右对齐数值、内存/显存横条及网络栏。沿用原生主题表面，不改共享材质。网络增加所选活动接口的 IPv4（有多个则全部列出），无 IPv4 时展示 IPv6；可选中复制，无公网探测请求。保留现有窗口位置和用户尺寸。

只读探测：本机 Ryzen 9 7945HX，联想 WMI 存在 GetCPUTemp/GetGPUTemp，但两者返回 0；GetFan1Speed/GetFan2Speed 报无效对象。无效返回继续显示“—”，不能冒充温度。下一步候选 LibreHardwareMonitor：新增依赖并可能需要底层驱动、权限和 AOT 兼容评估，属于新增影响，待确认接入方式；本轮不安装驱动。上游参考：[Legion Toolkit CPU 传感器实现](https://github.com/LenovoLegionToolkit-Team/LenovoLegionToolkit/blob/master/LenovoLegionToolkit.Lib/Controllers/Sensors/Providers/CpuSensorProvider.cs)。

规划：快照加地址字段 → 后台枚举所选网卡地址 → 内容紧凑分块/图标/横条 → 本地化 → 快速采集检查、Debug 构建与重启。验收：同一网卡 IP/速率一致，无泄露到日志，保留位置，明确传感器边界。未公开发布。

传感器扩展提案（待确认）：增加可选 LibreHardwareMonitor 采集组件，先在本机验证 Tctl/Tdie、CPU Package 功耗、GPU 温度/时钟，再决定纳入产品。采集与 UI 隔离，缺失值维持不可用，禁止写风扇/超频参数；不把整个 DeskBox 改为强制管理员。需要单独核实驱动来源、许可、安装/卸载、普通权限与 AOT 发布。此提案尚未执行。

第二轮实现：紧凑主题分块、指标图标、右对齐数值与较小间距；网络新增可选中复制的 IP，按所选网卡动态刷新，不记录真实地址到日志。12 种语言增加 IP 键。算法、真实读取、IP 格式及启停共 12 项快速检查通过；Debug 构建 0 错误、22 个既有警告。唯一标准 Debug 实例重启成功，日志确认实时数据渲染。完整测试与人工视觉对照未运行，比例与图标待用户实机验收；温度扩展保持待确认。

用户已确认开始开发。首版基础指标、1/2/5 秒刷新、GPU/网卡选择及不可用行开关；不做历史曲线或硬件控制。系统频率与真实有效频率有区别，不承诺温度/功耗/风扇。最终原生视觉统一在后续阶段验收。

## 3. 开发规划

第四轮（用户已确认执行）：先用固定版本 LHM 独立探测 7945HX 传感器与依赖，再决定正式 CPU 后端；GPU 接 NVIDIA NVML 并匹配所选适配器身份。UI 按新技能实现动态负载扇形、温度显示状态、统一字体与横条布局。扩展快照而不改变已有用户设置/位置；只读传感器，不写硬件控制参数。验证采用短探测/算法与 Debug 构建，完整测试和 AOT 发布另记未验证。当前进行中，未公开发布。

第四轮实施记录：独立探测确认缺少 PawnIO 时 CPU 温度/功耗不可用；使用官方 PawnIO 2.2.0 安装器（有效 Authenticode 签名 namazso.eu），SHA256 `1f519a22e47187f70a1379a48ca604981c4fcf694f4e65b734aaa74a9fba3032`，本机安装后读取成功。驱动不自动安装、不复制 GamePP/HWiNFO 私有组件，不写硬件控制。需要撤回时可在 Windows 已安装应用中卸载 PawnIO，CPU 扩展会恢复不可用，基础指标继续运行。

正式实现新增 DeskBox.SensorHost（LHM 0.9.6、独立 JIT 进程），通过重定向管道传输两项 CPU 数值，6 秒过期后丢弃；停止采集关闭并终止超时宿主。NVIDIA 使用系统驱动 NVML，按所选适配器 LUID→PCI 地址匹配温度、频率和功耗。新增快照字段保持旧配置兼容。UI 占用图标按百分比填充，温度按可配置显示阈值变色；主行字体统一 14 DIP，CPU/GPU 标题 16 DIP，网络速率同行、IP 可复制，表面使用主题资源。未读取到风扇转速，不以零伪装。

第四轮快速验收：14 项通过，包括真实 CPU 温度/功耗、GPU 温度/频率/功耗、网络 IP 格式及采集启停。示例快照 CPU 86°C/51W、GPU 50°C/9.5W，仅代表采集时刻。Debug 编译通过（0 错误，22 个既有警告）；实际主程序日志确认 CPU/GPU 温度与基础指标已渲染，独立宿主父进程为当前 DeskBox。桌面背景窗口无法由当前自动化接口截图，人工视觉验收不标记通过。

最终复核：14 项快速检查再次通过，`git diff --check` 通过，12 种语言各 27 个监控键一致；唯一标准 Debug 实例已重启。主程序退出后确认没有遗留 CPU 采集宿主，再次启动时只有对应父进程的一份宿主。完整测试未运行，可按下方 x64 聚焦测试命令补充；不将本地构建与读数验证视为完整上线验收。

按关联规划四项任务执行。当前工作区有用户未提交修改，沿用现有功能分支，不复制或重置用户改动，不自动提交。必要聚焦检查和 Debug 构建按 AGENTS.md 执行，不运行完整测试套件。
