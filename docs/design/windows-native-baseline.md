# Windows 原生 UI 强制基线

日期：2026-10-02。用户已明确要求：DeskBox 整体看起来应属于 Windows 系统原生界面。此要求适用于现有卡片、菜单、设置与未来的性能监控卡片，优先于此前 HTML 预览、局部样式和仅以现有源码为依据的视觉规则。

## 官方依据

- [Windows 材质](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/materials)：区分常驻界面与临时浮出界面的材质角色。
- [Mica](https://learn.microsoft.com/en-us/windows/apps/design/style/mica)：常驻窗口使用的动态、不透明材质，具有主题、背景及激活状态响应。
- [Acrylic](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)：背景亚克力用于菜单等临时界面；避免叠加多层亚克力、大面积背景亚克力和直接在亚克力上放强调色文字；需要透明效果关闭、省电和高对比度回退。
- [Windows 字体](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/typography)：遵循系统字体与文字层级，保留中文字体回退和文字缩放。
- [NavigationView](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/navigationview)：优先使用原生导航控件与状态，而不是用通用按钮模拟系统导航。
- [WinUI Gallery](https://github.com/microsoft/WinUI-Gallery)：官方控件示例及实现参考；实际运行的 WinUI 控件是验收对照。

## 必须遵守的规则

1. 原生控件、系统语义资源和窗口材质为第一选择。不得以网页仿制、AI 图片或固定颜色作为原生效果的验收依据。
2. 常驻桌面卡片优先评估系统 Mica；菜单沿用原生 MenuFlyout 的材质。保留合理的用户外观选择，但默认路径应符合 Windows 材质角色，不用额外强染色和渐变制造“磨砂感”。
3. 共享外壳统一管理材质、轮廓、描边、阴影、主题及激活状态；内容组件不能叠加自己的外壳材质或阴影。不能通过修改单张标签卡片补偿共享外壳的问题。
4. 使用 WinUI 默认字体层级、主题画刷和状态。强调色主要用于选择指示和操作；文字与材质组合须保证可读性。分隔线只表达必要分组，不形成深色贯穿栏。
5. 导航优先评估 NavigationView；若窄侧栏或自动方向规则无法满足，先明确限制，再复用原生资源和可访问性语义。不能默认硬编码一套选中态颜色与透明度。
6. 圆角和间距按具体 WinUI 控件与表面角色确定，不能把“卡片 16、内部 8”作为所有窗口的统一硬值。物理像素截图不能直接转成 DIP。
7. 动画采用原生控件行为和系统动画偏好。默认不额外添加应用图标上浮、装饰循环或发光；只有明确的交互需要才增加。
8. 性能监控卡片沿用同一共享外壳、文字层级、主题和设置控件。数字、单位、趋势图属于内容，不为此另建一套仪表盘视觉；数据更新不得重建窗口或持续播放装饰动画。

## 当前源码发现与下一轮范围

以下是代码审查结论，不等于运行时视觉认证：

- `WidgetMaterialVisualCalculator.BuildContentTintColor` 会额外混入强调色；`CalculateMica/CalculateAcrylic` 定义自有材质参数。需要与系统默认材质对照，区分用户覆盖和默认路径。截图偏粉的确切贡献尚需运行时确认。
- 标签分类已按用户要求撤下，后续原生视觉验收针对当前保留的卡片与性能监控。
- 标签分隔线已引用系统画刷，但截图仍显突兀；需核对宿主资源投射、主题、长度和对比度，不仅修改颜色常量。
- HTML 预览只保留为历史试验，不能作为后续原生实现的规范。

建议实施顺序：先建立共享外壳的原生默认材质与资源基线；再处理导航及分隔；最后逐类核对标题、内容与浮出界面。涉及共享材质和多个窗口的调整，实施前明确影响范围及用户配置兼容策略。

## 验收要求

在同一台机器、同一主题、同一屏幕和 DPI 下，与 Windows 设置、右键菜单及 WinUI Gallery 做并排运行对照。按各自角色比较材质，不要求常驻卡片与临时菜单颜色完全相同。

检查浅色、深色、激活/失活、透明效果关闭、高对比度、125%/150% DPI、中文长文本、键盘焦点、悬停、菜单及边框缩放。确认排序、分类、多分类关联和已配置行列不受外观修改影响。
