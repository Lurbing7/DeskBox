## 功能与数据

- [ ] 创建/启用入口有效，重复操作不产生第二个单例，重启恢复配置。
- [ ] 初次采样、不可用、失败与有效零值明确区分，不出现虚构的温度、功耗、频率或容量。
- [ ] CPU 在空闲/负载变化时合理响应，0–100%；说明与任务管理器效用口径区别，不强求数值逐秒相同。
- [ ] 内存显示物理内存已用/总量，与同一时刻系统数据合理对应。
- [ ] GPU 按已选适配器显示最忙引擎负载；多进程/多引擎不错误求和为总占用。
- [ ] 显存用量和容量来自同一适配器；共享内存与专用显存分开；无容量时不绘制伪造进度。
- [ ] 单网卡速率使用实际时间差，选择及自动回退明确；断网、设备变化和计数器重置不形成异常尖峰。
- [ ] 1/2/5 秒采样设置及 GPU/网卡选择可保存，不受系统语言影响。

## 生命周期与成本

- [ ] 非 UI 线程采集，采样不重叠；后台失败不阻塞窗口拖动、缩放或其他卡片。
- [ ] 隐藏/停用/关闭停止采集和释放资源；恢复时重新预热差分指标。
- [ ] 多次启停不持续增加 PDH 句柄、线程或内存；记录启用前后对照与测量时长。
- [ ] 基础版无新增驱动；第四轮已确认扩展使用独立 CPU 采集进程及本机官方 PawnIO 驱动。验证无硬件控制、遥测上传和整个 DeskBox 强制管理员要求，普通权限仍需独立验收。
